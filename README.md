# csharp-poo-curso

Código do curso "C# COMPLETO: Programação Orientada a Objetos + Projetos" (Nelio Alves, Udemy), organizado por capítulo.

- `02-logica-de-programacao/` entrada e saída, operadores, if-else, funções, while, for
- `03-classes-atributos-metodos/` classes, objetos, métodos, ToString, membros estáticos

Cada pasta é um projeto console. Para rodar:

```
dotnet run --project 03-classes-atributos-metodos/02-triangulo-classe
```
